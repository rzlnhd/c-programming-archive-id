A collection of C programs written during my college years, covering **fundamental data structures, algorithms, and basic programming exercises**.  
All file names and most program interfaces are in **Indonesian**, reflecting the original coursework.

---

## 📂 Project Structure

- **array_and_matrix/**  
  Array manipulation and matrix operations (transpose, reverse, sum of arrays).

- **binary_number/**  
  Binary conversions, binary search, and binary search tree implementations.

- **sorting/**  
  Classic sorting algorithms: heap sort, merge sort, quick sort, list sorting.

- **stack_and_queue/**  
  Stack and queue implementations (linked list, circular, priority).

- **linked_list/**  
  Linked list operations (insert, delete, circular lists, stack/queue with lists).

- **loop_exercises/**  
  Loop‑based exercises (patterns, star triangles, etc.).

- **utilities/**  
  Miscellaneous programs (grade conversion, math functions, time calculations).

---

## ⚡ How to Compile

These programs were originally written in **CodeBlocks (MinGW)**.  
They have been re‑tested with **GCC (MSYS2/MinGW‑w64) in VS Code**.

Example compile command:
```bash
gcc file.c -o file.exe
./file.exe
```
